In Python, `None`{.python} is a special value that represents the **absence of a value**. It's used to indicate that something has no meaningful result or that a variable hasn't been assigned a value yet.

# What is None?

`None`{.python} is a keyword in Python that represents "nothing" or "no value". As it is a keyword, it is not possible to create a variable named `None`{.python}. You can assign it to variables:

```py-cell
x = None
print(x)
print(type(x))
```

The type of `None`{.python} is `NoneType`{.python}.

# None and Variables

You can use `None`{.python} to indicate that a variable hasn't been set to a meaningful value yet:

```py-cell
user_age = None

print(user_age)
```
